- Date: 2026-11-03
- 환경: macOS, zsh

## Study 내용 

### 1. 컴퓨터 구조
- SSD(저장, 영구) → RAM(작업, 휘발) → CPU(계산)
- 결과를 남겨 추후 재부팅후에도 참조하려면 파일로 SSD에 저장해야 한다

### 2. 파일 시스템과 경로
- `/`로 시작하면 절대 경로, 그 외는 상대 경로
- `~` = 홈 폴더(`/Users/bagbeomsu`), `..` = 한 칸 위
- 공백이 있는 이름은 `\ ` 또는 `" "`로 처리

```bash
$ cd ../../Desktop               # 상대 경로
$ cd /Users/bagbeomsu/Desktop    # 절대 경로
$ echo "3" > result.txt          # 파일로 저장
```

### 3. cp, mv, rm
- `mv`: 목적지가 폴더면 이동, 없는 이름이면 이름 바꾸기
- 폴더로 옮길 땐 `mv 파일 폴더/`. / 를 붙여 폴더가 없으면 에러가 나도록 안전장치
- `rm`은 영구 삭제. `/`가 안전장치가 아니므로 `ls`로 먼저 확인

### 4. 프로그램과 프로세스
- 프로그램 = SSD의 파일, 프로세스 = RAM에서 실행 중인 상태(PID로 관리)

```bash
$ ps aux | grep sleep    # PID 찾기
$ kill 43550             # 종료 (안 되면 kill -9)
```

## 배운 점
- mv 명령어 사용시 끝에 / 를 붙여 오타가 나도 파일 이름이 조용히 변경되지 않고 에러로 알려준다.
- 명령어 실행 후 `ls`로 결과가 의도대로 됐는지 확인하고, 예상과 다르면 `history`로 입력한 명령어를 추적한다.
